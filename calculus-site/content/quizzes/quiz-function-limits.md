  - id: q-funlim-1
    type: choice
    question: 函数 $f(x)=\frac{|x|}{x}$（$x\neq 0$）在 $x\to 0$ 时极限是否存在？
    options:
      - 存在，且等于 1
      - 存在，且等于 -1
      - 不存在
      - 存在，且等于 0
    answer: C
    explanation: 右侧极限为 1，左侧极限为 -1，左右极限不相等，因此极限不存在。
  - id: q-funlim-2
    type: choice
    question: '$\displaystyle \lim_{x\to 2} (x^2+1)$ 等于？'
    options:
      - 3
      - 4
      - 5
      - 不存在
    answer: C
    explanation: 将 $x=2$ 代入得 $2^2+1=5$。
