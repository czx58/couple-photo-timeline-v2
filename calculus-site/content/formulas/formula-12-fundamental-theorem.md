usage: >-
  牛顿-莱布尼茨公式（微积分基本定理）是连接定积分与不定积分的核心工具，它指出：若 $f(x)$ 在 $[a,b]$ 上连续，且 $F(x)$ 是
  $f(x)$ 的一个原函数（即 $F'(x)=f(x)$），则 $\int_a^b f(x) \, dx = F(b) - F(a)$。


  **使用场景**：

  - 计算定积分时，只需找到被积函数的一个原函数 $F(x)$，然后代入上下限求差，无需利用定义求极限。

  - 适用于连续函数（或分段连续且原函数存在的情形），常用于物理中的位移、功、面积等计算。


  **注意事项**：

  - 公式成立要求 $f$ 在 $[a,b]$ 上连续（或至少在积分区间上可积且存在原函数）。若 $f$ 有间断点，需分段处理。

  - $F(x)$ 必须是 $f(x)$ 的原函数，即 $F'(x)=f(x)$，不能随意取其他函数。

  - 若 $a > b$，公式仍适用，但注意 $\int_a^b f(x)\,dx = F(b)-F(a)$ 会自动处理符号。

  - 原函数不唯一，但任意两个原函数相差常数，相减后常数抵消，不影响结果。


  **常见变形**：

  - 变量替换：令 $u=\phi(x)$，则 $\int_a^b f(\phi(x))\phi'(x)\,dx =
  \int_{\phi(a)}^{\phi(b)} f(u)\,du$，注意积分限相应改变。

  - 分部积分：$\int_a^b u\,dv = [uv]_a^b - \int_a^b v\,du$，常用于乘积函数的积分。

  - 变上限积分求导：若 $G(x)=\int_a^x f(t)\,dt$，则 $G'(x)=f(x)$，这是公式的微分解读。
examples:
  - problem: '计算定积分 $\int_0^1 (3x^2 + 2x) \, dx$。'
    solution: |-
      1. 找出被积函数 $f(x)=3x^2+2x$ 的一个原函数。
         - 对 $3x^2$ 积分得 $x^3$（因为 $\frac{d}{dx}(x^3)=3x^2$）。
         - 对 $2x$ 积分得 $x^2$（因为 $\frac{d}{dx}(x^2)=2x$）。
         - 所以 $F(x)=x^3+x^2$。
      2. 应用牛顿-莱布尼茨公式：
         $$\int_0^1 (3x^2+2x)\,dx = F(1) - F(0) = (1^3+1^2) - (0^3+0^2) = 2 - 0 = 2.$$
      3. 因此结果为 $2$。
  - problem: '求定积分 $\int_1^e \frac{1}{x} \, dx$。'
    solution: >-
      1. 被积函数为 $f(x)=\frac{1}{x}$，其一个原函数为 $F(x)=\ln|x|$（在 $(0,+\infty)$ 上即 $\ln
      x$）。

      2. 应用牛顿-莱布尼茨公式：
         $$\int_1^e \frac{1}{x}\,dx = F(e) - F(1) = \ln e - \ln 1 = 1 - 0 = 1.$$
      3. 因此结果为 $1$。
