relatedTopicSlugs:

usage: >-
  麦克劳林展开是泰勒展开在 $x_0=0$ 时的特殊形式，用于将函数表示为幂级数。对于 $\ln(1+x)$，其展开式为 $\ln(1+x) =
  \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n}$，收敛域为 $|x|<1$（在 $x=1$
  时也收敛，但需注意端点）。


  **使用场景**：

  - 计算 $\ln(1+x)$ 在 $x$ 接近 0 时的近似值。

  - 求极限、积分或微分时，将对数函数转化为幂级数，便于运算。

  - 在数值分析中，用于计算对数值。


  **注意事项**：

  - 展开式仅在 $|x|<1$ 时收敛，超出范围需通过变换（如 $\ln(1+x) = \ln x + \ln(1+1/x)$）处理。

  - 当 $x=1$ 时，级数收敛到 $\ln 2$，但收敛速度较慢。

  - 展开式是交错级数，截断误差不超过首项绝对值。


  **常见变形**：

  - 用 $-x$ 替换 $x$：$\ln(1-x) = -\sum_{n=1}^{\infty} \frac{x^n}{n}$。

  - 两式相减：$\ln\frac{1+x}{1-x} = 2\sum_{n=0}^{\infty} \frac{x^{2n+1}}{2n+1}$，收敛域
  $|x|<1$。

  - 通过变量替换，可求 $\ln(a+x)$ 的展开。
examples:
  - problem: '利用 $\ln(1+x)$ 的麦克劳林展开，求 $\lim_{x \to 0} \frac{\ln(1+x) - x}{x^2}$。'
    solution: >-
      **解**：

      由麦克劳林展开：$\ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots$。

      代入分子：$\ln(1+x) - x = -\frac{x^2}{2} + \frac{x^3}{3} - \cdots$。

      除以 $x^2$：$\frac{\ln(1+x) - x}{x^2} = -\frac{1}{2} + \frac{x}{3} - \cdots$。

      取极限：$\lim_{x \to 0} \left(-\frac{1}{2} + \frac{x}{3} - \cdots\right) =
      -\frac{1}{2}$。

      所以极限为 $-\frac{1}{2}$。
  - problem: 求 $\ln(1.1)$ 的近似值，要求误差不超过 $0.001$。
    solution: >-
      **解**：

      取 $x=0.1$，展开式：$\ln(1.1) = 0.1 - \frac{0.1^2}{2} + \frac{0.1^3}{3} -
      \frac{0.1^4}{4} + \cdots$。

      计算各项：$0.1 = 0.1$，$\frac{0.01}{2}=0.005$，$\frac{0.001}{3}\approx
      0.000333$，$\frac{0.0001}{4}=0.000025$。

      交错级数截断误差不超过下一项绝对值。取前三项：$0.1 - 0.005 + 0.000333 = 0.095333$，下一项为
      $0.000025$，误差小于 $0.000025$，满足精度。

      所以 $\ln(1.1) \approx 0.09533$（四舍五入）。
