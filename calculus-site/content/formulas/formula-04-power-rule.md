title: 幂函数求导

latex: '(x^n)'' = nx^{n-1}'
plaintext: (x^n)' = n x^(n-1)
relatedTopicSlugs:

usage: >-
  幂函数求导公式 $(x^n)' = nx^{n-1}$ 是导数中最基础、最常用的公式之一，适用于所有实数指数
  $n$（包括整数、分数、负数）。它主要用于直接求幂函数的导数，以及作为复合函数求导（如链式法则）和隐函数求导的基础。


  **使用场景**：

  - 求形如 $f(x) = x^n$ 的函数的导数。

  - 在求多项式函数（如 $3x^4 - 2x^2 + x$）时，结合常数倍和加减法则逐项求导。

  - 当 $n$ 为分数或负数时（如 $\sqrt{x} = x^{1/2}$，$\frac{1}{x} = x^{-1}$）也适用。


  **注意事项**：

  - 当 $n = 1$ 时，$(x)' = 1$，这是特例。

  - 当 $n = 0$ 时，$x^0 = 1$（$x \neq 0$），其导数为 $0$，但公式给出 $0 \cdot x^{-1} = 0$（需注意 $x
  \neq 0$）。

  - 若底数是 $x$ 的复合函数（如 $(\sin x)^n$），需使用链式法则，不能直接套用此公式。

  - 若指数是变量（如 $a^x$ 或 $x^x$），此公式不适用，应使用指数函数或对数求导法。


  **常见变形**：

  - 常数倍：$(c x^n)' = c n x^{n-1}$。

  - 多项式求导：逐项使用公式。

  - 根式与分式：先将根式或分式转化为幂的形式，如 $\sqrt[3]{x^2} = x^{2/3}$，$\frac{1}{x^2} =
  x^{-2}$，再求导。
examples:
  - problem: '求函数 $f(x) = 3x^5 - 2x^3 + \frac{1}{x} + \sqrt{x}$ 的导数。'
    solution: >-
      先将各分式和根式转化为幂函数形式：

      $\frac{1}{x} = x^{-1}$，$\sqrt{x} = x^{1/2}$。

      逐项求导（利用常数倍和加减法则）：

      - 对 $3x^5$：$(3x^5)' = 3 \cdot 5x^{4} = 15x^4$。

      - 对 $-2x^3$：$(-2x^3)' = -2 \cdot 3x^{2} = -6x^2$。

      - 对 $x^{-1}$：$(x^{-1})' = -1 \cdot x^{-2} = -x^{-2}$。

      - 对 $x^{1/2}$：$(x^{1/2})' = \frac{1}{2}x^{-1/2}$。

      合并得到：

      $$f'(x) = 15x^4 - 6x^2 - x^{-2} + \frac{1}{2}x^{-1/2} = 15x^4 - 6x^2 -
      \frac{1}{x^2} + \frac{1}{2\sqrt{x}}.$$
  - problem: '求函数 $g(x) = \frac{1}{x^3} - 4\sqrt[4]{x^3}$ 的导数。'
    solution: >-
      先将各项化为幂函数形式：

      $\frac{1}{x^3} = x^{-3}$，$\sqrt[4]{x^3} = x^{3/4}$。

      逐项求导：

      - 对 $x^{-3}$：$(x^{-3})' = -3x^{-4}$。

      - 对 $-4x^{3/4}$：$(-4x^{3/4})' = -4 \cdot \frac{3}{4}x^{3/4 - 1} =
      -3x^{-1/4}$。

      合并得到：

      $$g'(x) = -3x^{-4} - 3x^{-1/4} = -\frac{3}{x^4} - \frac{3}{\sqrt[4]{x}}.$$
