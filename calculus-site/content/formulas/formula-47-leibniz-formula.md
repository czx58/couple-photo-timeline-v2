---
title: 莱布尼茨公式
slug: leibniz-formula
category: 导数
latex: '(uv)^{(n)} = \sum_{k=0}^{n} C_n^k u^{(n-k)} v^{(k)}'
plaintext: '(uv)^(n) = sum_{k=0}^{n} C(n,k) u^(n-k) v^(k)'
relatedTopicSlugs:
  - derivative-rules
usage: >-
  莱布尼茨公式用于求两个函数乘积的高阶导数，它类似于二项式定理，将乘积的 $n$ 阶导数展开为各项的线性组合。


  **使用场景**：当需要计算形如 $u(x)v(x)$ 的 $n$ 阶导数，且 $u$ 或 $v$
  的高阶导数具有规律（如多项式、指数函数、三角函数等）时，使用该公式可以简化计算。


  **注意事项**：

  - 公式中的 $C_n^k$ 是组合数，即 $C_n^k = \frac{n!}{k!(n-k)!}$。

  - 各项中 $u$ 的阶数从 $n$ 降到 $0$，$v$ 的阶数从 $0$ 升到 $n$。

  - 当 $u$ 或 $v$ 的某阶导数为零时，后续项可省略。


  **常见变形**：

  - 当 $v$ 为一次函数时，公式只保留前两项。

  - 当 $u$ 或 $v$ 为多项式时，阶数超过多项式次数后导数为零，因此求和项数有限。
examples:
  - problem: 求函数 $y = x^2 e^x$ 的 $n$ 阶导数。
    solution: >-
      令 $u = x^2$，$v = e^x$。


      由莱布尼茨公式：

      $$(uv)^{(n)} = \sum_{k=0}^{n} C_n^k u^{(n-k)} v^{(k)}$$


      计算各阶导数：

      - $u' = 2x$, $u'' = 2$, $u^{(m)} = 0$（$m \geq 3$）

      - $v^{(k)} = e^x$ 对所有 $k$ 成立。


      因此，当 $n \geq 2$ 时，只有 $k = n, n-1, n-2$ 三项非零（因为 $u^{(n-k)}$ 非零要求 $n-k \leq
      2$）。


      所以：

      $$y^{(n)} = C_n^0 x^2 e^x + C_n^1 (2x) e^x + C_n^2 (2) e^x$$


      化简：

      $$y^{(n)} = e^x \left[ x^2 + 2nx + n(n-1) \right]$$


      当 $n=1$ 时，直接求导得 $y' = 2xe^x + x^2 e^x = e^x(x^2+2x)$，与公式一致（此时 $n(n-1)=0$）。
  - problem: 求函数 $y = x \sin x$ 的 $10$ 阶导数。
    solution: >-
      令 $u = x$，$v = \sin x$。


      莱布尼茨公式：

      $$(uv)^{(10)} = \sum_{k=0}^{10} C_{10}^k u^{(10-k)} v^{(k)}$$


      计算：

      - $u' = 1$, $u'' = 0$，所以 $u^{(m)}=0$ 当 $m \geq 2$。

      - $v^{(k)} = \sin\left(x + \frac{k\pi}{2}\right)$（因为 $\sin x$ 的 $k$ 阶导数为
      $\sin(x + k\pi/2)$）。


      因此，只有 $k = 9$ 和 $k = 10$ 两项非零（因为 $10-k \leq 1$）。


      所以：

      $$y^{(10)} = C_{10}^9 u' v^{(9)} + C_{10}^{10} u v^{(10)}$$


      计算：

      - $C_{10}^9 = 10$, $u' = 1$, $v^{(9)} = \sin(x + 9\pi/2) = \sin(x + 4\pi +
      \pi/2) = \sin(x + \pi/2) = \cos x$

      - $C_{10}^{10} = 1$, $u = x$, $v^{(10)} = \sin(x + 10\pi/2) = \sin(x +
      5\pi) = \sin(x + \pi) = -\sin x$


      因此：

      $$y^{(10)} = 10 \cos x - x \sin x$$
