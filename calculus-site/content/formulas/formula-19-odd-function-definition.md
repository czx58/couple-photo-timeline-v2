---
title: 奇函数定义
slug: odd-function-definition
category: 函数
latex: f(-x) = -f(x)
plaintext: f(-x) = -f(x)
relatedTopicSlugs:
  - functions-basics
usage: >-
  奇函数定义用于判断函数是否关于原点对称，即图像绕原点旋转180°后与原图重合。使用场景包括：证明函数的奇偶性、简化定积分计算（若积分区间对称且函数为奇函数，则积分为0）、分析函数图像的对称性。注意事项：定义域必须关于原点对称，否则不是奇函数；判断时需对定义域内所有
  $x$ 验证 $f(-x) = -f(x)$ 是否恒成立。常见变形：将定义式改写为 $f(-x) + f(x) =
  0$；若函数可导，则奇函数的导数为偶函数；若函数的原函数存在，则原函数不一定是奇函数（需满足特定常数条件）。
examples:
  - problem: 判断函数 $f(x) = x^3 - 2x$ 是否为奇函数。
    solution: |-
      **解**：
      1. 定义域为 $\mathbb{R}$，关于原点对称。
      2. 计算 $f(-x)$：
         $$f(-x) = (-x)^3 - 2(-x) = -x^3 + 2x$$
      3. 比较 $-f(x)$：
         $$-f(x) = -(x^3 - 2x) = -x^3 + 2x$$
      4. 因为 $f(-x) = -f(x)$ 对任意 $x$ 成立，所以 $f(x)$ 是奇函数。
  - problem: 已知函数 $g(x)$ 是奇函数，且 $g(2) = 5$，求 $g(-2)$ 的值。
    solution: |-
      **解**：
      1. 由奇函数定义，对于定义域内的任意 $x$，有 $g(-x) = -g(x)$。
      2. 令 $x = 2$，则 $g(-2) = -g(2)$。
      3. 代入 $g(2) = 5$，得 $g(-2) = -5$。
      4. 因此，$g(-2) = -5$。
