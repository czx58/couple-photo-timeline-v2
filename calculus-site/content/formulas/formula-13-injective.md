usage: >-
  **单射（一一映射）的定义**


  设函数 $f: A \to B$，若对任意 $x_1, x_2 \in A$，都有

  $$f(x_1) = f(x_2) \implies x_1 = x_2,$$

  则称 $f$ 为单射函数。


  **使用场景**：

  - 判断一个函数是否具有反函数（单射是存在反函数的必要条件之一）。

  - 在集合论、线性代数（线性变换的单射性）以及抽象代数（同态的单射性）中广泛使用。

  - 在证明两个元素相等时，有时通过证明它们的函数值相等来间接证明。


  **注意事项**：

  - 该定义只针对定义域内的元素，与值域无关；单射并不要求满射。

  - 证明单射时，通常假设 $f(x_1)=f(x_2)$，然后通过代数变形推出 $x_1=x_2$；不能反过来从 $x_1=x_2$
  推出函数值相等（这是函数的基本性质，不是单射的条件）。

  - 对于非严格单调函数（如二次函数），通常不是单射，除非限制定义域。


  **常见变形**：

  - 逆否命题形式：若 $x_1 \neq x_2$，则 $f(x_1) \neq f(x_2)$。这个形式常用于反证法。

  - 对于线性函数 $f(x)=kx+b$（$k\neq0$），显然是单射；对于指数函数、对数函数、严格单调的幂函数等也是单射。

  - 在有限集合上，单射等价于满射（若定义域和值域元素个数相同）。
examples:
  - problem: '**例1**：判断函数 $f: \mathbb{R} \to \mathbb{R}$，$f(x) = 3x - 2$ 是否为单射，并证明。'
    solution: |-
      **解**：
      1. 假设 $f(x_1) = f(x_2)$，即 $3x_1 - 2 = 3x_2 - 2$。
      2. 两边同时加2，得 $3x_1 = 3x_2$。
      3. 两边同时除以3，得 $x_1 = x_2$。
      4. 因此，根据单射定义，$f$ 是单射。
  - problem: '**例2**：判断函数 $g: \mathbb{R} \to \mathbb{R}$，$g(x) = x^2$ 是否为单射，并说明理由。'
    solution: |-
      **解**：
      1. 取 $x_1 = 1$，$x_2 = -1$，显然 $x_1 \neq x_2$。
      2. 计算函数值：$g(1) = 1^2 = 1$，$g(-1) = (-1)^2 = 1$。
      3. 因此 $g(x_1) = g(x_2)$ 但 $x_1 \neq x_2$，不满足单射定义。
      4. 所以 $g$ 不是单射。若限制定义域为 $[0, +\infty)$，则 $g$ 是单射。
