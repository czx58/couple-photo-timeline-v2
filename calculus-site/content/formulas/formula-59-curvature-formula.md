---
title: 曲率公式
slug: curvature-formula
category: 中值定理
latex: 'K = \frac{|y''''|}{(1 + y''^2)^{3/2}}'
plaintext: K = |y''| / (1 + y'^2)^(3/2)
relatedTopicSlugs:
  - monotonicity-extrema
usage: >-
  曲率公式用于计算平面曲线在某一点的弯曲程度，属于微分几何在微积分中的应用。它适用于显式函数 $y=f(x)$ 表示的曲线。使用公式 $K =
  \frac{|y''|}{(1 + y'^2)^{3/2}}$ 时，需先求出函数的一阶导数 $y'$ 和二阶导数
  $y''$，然后代入计算。注意：公式适用于二阶可导函数，且分母不为零（即 $1+y'^2 \neq 0$，恒成立）。常见变形：若曲线由参数方程
  $x=x(t), y=y(t)$ 给出，则曲率公式为 $K = \frac{|x'y'' - y'x''|}{(x'^2 +
  y'^2)^{3/2}}$；若曲线由极坐标 $r=r(\theta)$ 给出，则 $K = \frac{|r^2 + 2r'^2 - rr''|}{(r^2
  + r'^2)^{3/2}}$。曲率半径 $\rho = \frac{1}{K}$（当 $K \neq 0$ 时）。
examples:
  - problem: '求曲线 $y = x^2$ 在点 $(1,1)$ 处的曲率。'
    solution: >-
      解：

      1. 求一阶导数：$y' = 2x$。

      2. 求二阶导数：$y'' = 2$。

      3. 代入点 $(1,1)$：$y'(1) = 2$，$y''(1) = 2$。

      4. 代入曲率公式：$K = \frac{|2|}{(1 + 2^2)^{3/2}} = \frac{2}{5^{3/2}} =
      \frac{2}{5\sqrt{5}}$。

      因此，曲线在点 $(1,1)$ 处的曲率为 $\frac{2}{5\sqrt{5}}$。
  - problem: '求曲线 $y = \ln x$ 在点 $(1,0)$ 处的曲率半径。'
    solution: >-
      解：

      1. 求导数：$y' = \frac{1}{x}$，$y'' = -\frac{1}{x^2}$。

      2. 在点 $(1,0)$ 处：$y'(1) = 1$，$y''(1) = -1$。

      3. 代入曲率公式：$K = \frac{|-1|}{(1 + 1^2)^{3/2}} = \frac{1}{2^{3/2}} =
      \frac{1}{2\sqrt{2}}$。

      4. 曲率半径 $\rho = \frac{1}{K} = 2\sqrt{2}$。

      因此，曲线在点 $(1,0)$ 处的曲率半径为 $2\sqrt{2}$。
