---
title: 常数求导
slug: derivative-constant
category: 导数
latex: (C)' = 0
plaintext: (C)' = 0
relatedTopicSlugs:
  - derivative-rules
usage: >-
  常数函数 $y = C$（其中 $C$ 为常数）的导数为零，即 $(C)' =
  0$。该公式用于求常数函数的导数，也常用于求导运算中常数项的处理。注意：常数函数是斜率为零的直线，其变化率为零。常见变形：若函数为 $f(x) = C
  \cdot g(x)$，则 $f'(x) = C \cdot g'(x)$（常数因子可提到导数符号外）。
examples:
  - problem: 求函数 $y = 5$ 的导数。
    solution: 由常数求导公式，$(5)' = 0$。因此 $y' = 0$。
  - problem: 求函数 $f(x) = 3x^2 + 7$ 的导数。
    solution: >-
      根据导数运算规则，常数项 $7$ 的导数为 $0$，而 $3x^2$ 的导数为 $3 \cdot 2x = 6x$。因此 $f'(x) = 6x +
      0 = 6x$。
